This folder owns the agentic-on-DSPy track.

It starts from DSPy-compatible data and programs, but its artifacts stay isolated from the pure DSPy track.

- `data/`: DSPy pickles for this track
- `results.tsv`: structured run metrics
- `runs/`: per-example predictions
- `programs/`: saved compiled DSPy programs
- `prompts/`: optional agent-authored prompt notes
- `dev_sessions.tsv`: reserved for developer or Codex effort tracking
